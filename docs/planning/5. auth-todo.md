## Current Auth Shape

```text
Browser
  |
  v
Next.js auth route handlers
  |
  v
Django REST API + Simple JWT
  |
  v
Django User model
```

The browser should not directly store JWTs in local storage. Next.js stores the Django JWTs in HTTP-only cookies.
