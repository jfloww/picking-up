# Oracle Database Plan

## Decision

Use Oracle Database on Oracle Cloud Infrastructure for the production database.

The application architecture becomes:

```text
Next.js frontend on Vercel
        |
        v
Django REST API on OCI VM
        |
        v
Oracle Database on OCI
```

## Why Oracle Database

- The project already has an OCI account.
- Oracle Cloud has Always Free services with limits.
- Keeping backend and database inside OCI can reduce deployment complexity later.
- It gives practical experience with cloud infrastructure, networking, database credentials, and production-style deployment.

## Local Development

SQLite can remain the temporary local development fallback while the backend is still being built.

Before real deployment, Django must be configured and tested against Oracle Database.

Local sequence:

```text
1. Build Django APIs against SQLite for speed.
2. Add Oracle Database settings.
3. Run migrations against Oracle Database.
4. Run backend tests against Oracle Database before deployment.
```

## Django Direction

Django supports Oracle through its Oracle database backend.

Expected dependency:

```text
oracledb
```

Expected production settings shape:

```text
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.oracle",
        "NAME": env("ORACLE_DB_DSN"),
        "USER": env("ORACLE_DB_USER"),
        "PASSWORD": env("ORACLE_DB_PASSWORD"),
    }
}
```

For Oracle Autonomous Database, wallet-based configuration may also be required. Track the actual OCI connection method before finalizing settings.

## Environment Variables

Planned variables:

```text
ORACLE_DB_USER=
ORACLE_DB_PASSWORD=
ORACLE_DB_DSN=
ORACLE_DB_WALLET_DIR=
ORACLE_DB_WALLET_PASSWORD=
```

The exact required variables depend on whether the database uses a direct connection string or an Autonomous Database wallet.

## Production Rules

- Do not use SQLite in production.
- Do not commit Oracle wallet files.
- Do not commit database passwords.
- Keep database credentials in environment variables.
- Run Django migrations during deployment.
- Create a backup/restore plan before storing important personal data.
