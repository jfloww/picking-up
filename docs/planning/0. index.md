# Planning Index

This folder records the current product and engineering direction for the to-do platform.

## Current Decision

Use Django for the shared backend, not Supabase.

```text
frontend/         -> Next.js desktop web app
backend/          -> Django REST API + Oracle Database on OCI
mobile-frontend/  -> future iPhone app using the same Django API
```

## Build Order

```text
1. Desktop web UI with responsive small-window support
2. Django backend with auth and task API
3. Connect frontend to backend
4. Deploy frontend and backend
5. Polish mobile browser/PWA
6. Build native iPhone app only if needed
```
