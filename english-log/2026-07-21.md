# English corrections — 2026-07-21

1. You wrote: "I have worked with mac and pull the work history."
   Better: "I worked on my Mac and pulled the latest changes."
   Why: "have worked" (present perfect) doesn't mix with the base-form "pull" — needed "pulled." Also "Mac" is capitalized as a product name, and "the work history" reads more naturally as "the latest changes."

2. You wrote: "I think claude environment is not same."
   Better: "I don't think the Claude environment is the same."
   Why: "Claude" is a proper noun (capitalize it). "is not same" needs an article: "is not the same," and "I think X is not" is more naturally phrased as "I don't think X is."

3. You wrote: "I don't know why but claude's coding styles look different between developing in windows and mac."
   Better: "I don't know why, but Claude's coding style looks different when developing on Windows versus Mac."
   Why: comma before "but" in a compound sentence; "Claude" and "Windows" capitalized; "in windows" → "on Windows"; "styles...look different between developing in X and Y" is awkward — "style looks different when developing on X versus Y" is the natural pattern.

4. You wrote: "One thing I want to ask about is my english expression."
   Better: "One thing I wanted to ask about is my English expressions."
   Why: "English" is always capitalized. "expression" (singular) should be plural since you mean expressions in general, not one specific phrase.

5. You wrote: "please create the folder and if I use wrong/awkard english expression please correct me and save it by daily."
   Better: "Please create the folder, and if I use a wrong or awkward English expression, please correct me and save it daily."
   Why: "awkard" → "awkward" (typo). "wrong/awkard english expression" needs an article — "a wrong or awkward English expression." "save it by daily" → "save it daily" (or "on a daily basis"); "by daily" isn't a standard English phrase.
