# English corrections — 2026-09-01

Source: resume bullet drafts for the Picking Up project.

1. You wrote: "using database transactions, row-level locking, and optimistic concurrency control to reject stale writes and roll back partial failures"
   Better: "using row-level locks and per-record version numbers so overlapping edits fail loudly instead of silently overwriting each other"
   Why: "transactions ... to roll back partial failures" restates the definition of a transaction, so it reads as padding to a technical reader. Name what the mechanism *prevented*, not what the mechanism *is*.

2. You wrote: "Designed six command APIs for multi-record task mutations"
   Better: "Designed six transactional command endpoints for task operations that mutate several rows at once"
   Why: "multi-record task mutations" stacks three nouns as modifiers, which forces the reader to unpack it. English resists long noun chains — unfold them into a relative clause ("operations that mutate several rows").

3. You wrote: "Enforced task hierarchy, scheduling, and case-insensitive category uniqueness rules through DRF validation, database constraints, and staged schema and data migrations."
   Better: "Pushed data-integrity rules down to the database — case-insensitive category uniqueness and CHECK constraints on hierarchy and scheduling — through add/backfill/enforce migration phases."
   Why: two comma lists in one sentence (three rules, three mechanisms) make the reader pair them up manually. Lead with the single idea, then use a dash to hold the examples.

4. You wrote: "Built and deployed a full-stack task and routine planner"
   Better: "Shipped and operated a full-stack task and routine planner"
   Why: grammatical, but "deployed" with no deployment detail after it reads as an empty claim. "Shipped and operated" implies ongoing ownership, and it sets up the migration detail that follows.

5. You wrote: "이렇게 지금 생각중이네 냉정하게 평가좀"
   Better (if writing this in English): "This is what I have so far — give me a blunt assessment."
   Why: "evaluate coldly" is a literal translation that sounds odd; native phrasing is "be blunt," "be brutally honest," or "don't sugarcoat it."
