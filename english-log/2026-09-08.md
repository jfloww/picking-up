# English corrections — 2026-09-08

Source: chat request to update the landing page hero mock.

1. You wrote: "update the home screen (the mock project showing page?)"
   Better: "update the home screen (the page that shows the project mockup?)"
   Why: English does not let an `-ing` verb sit in the middle of a noun stack like that — "showing" reads as modifying "project," not "page." Unfold it into a relative clause after the noun.

2. You wrote: "create the pr for the all the changes"
   Better: "create the PR for all the changes"
   Why: "the all the" doubles the determiner. "All the changes" already carries "the," so the leading one has to go.

3. You wrote: "we have some code updates, so can you ..."
   Better: "we've made some code updates, so could you ..."
   Why: "we have some code updates" states a fact about inventory; the present perfect ("we've made") says the work just happened, which is what motivates the request that follows.
